**BrainVault** is a premium, 100% offline puzzle game for Android. Built for speed and fun, it features three brain-training games to test your memory, math skills, and pattern recognition.

No accounts. No cloud. Just pure brain training when you need it.

---

## ✨ Features

*   🧩 **3 Unique Games:** Memory Grid, Quick Math, and Pattern Lock.
*   🏆 **Level & XP System:** Earn XP, level up, and unlock new challenges.
*   🪙 **Coin Economy:** Earn coins by winning games. Use them for hints.
*   🎁 **Daily Challenges:** Complete daily brain teasers for bonus rewards.
*   🎨 **Premium UI/UX:** Built with Jetpack Compose, featuring a clean, modern aesthetic.
*   🔒 **100% Offline & Private:** All progress and scores are saved locally using Room DB.
*   💰 **Ad-Aware:** Optional AdMob banners, interstitials, and rewarded ads that never block gameplay.

---

## 🛠️ Tech Stack

*   **Language:** Kotlin
*   **UI:** Jetpack Compose (Material 3)
*   **Local Database:** Room DB
*   **Navigation:** Compose Navigation
*   **Monetization:** Google AdMob & UMP Consent
*   **Architecture:** MVVM (Model-View-ViewModel)
